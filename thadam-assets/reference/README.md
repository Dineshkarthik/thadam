# Reference mockups

These WebP files are AI-generated homepage concept mockups, kept only as layout references:

- `thadam-hero-light.webp`
- `thadam-hero-light-alternate.webp`
- `thadam-hero-dark-concept.webp`
- `thadam-hero-composition.webp`

They have lettering baked into the image: an AI-drawn logo, headline, and buttons. That breaks the brand rule to use the SVGs in `../brand/svg/` unmodified. Never ship them, copy them into `website/`, or use them on public pages. For website art, use the text-free illustrations in `../brand/illustrations/` and render all text in HTML.
