# Thadam Brand Guidelines

## Canonical identity
The official Thadam mark is a **geometric capital T** with a signal-orange crossbar detail. The T is the single source of visual identity across the project. Do not substitute a generic network, diamond, or connected-node symbol.

## Positioning
Thadam is an open-source, Rust-first data plane for robotics and industrial systems. It connects device protocols to modern data platforms with edge-native processing and reliable delivery.

## Tagline
**The open data plane for robotics.**

## Visual tokens
- Ink: `#151719`
- Paper: `#F5F4F0`
- Signal orange: `#F26A3D`
- Steel: `#8B9298`
- Typeface direction: Inter / system sans-serif

## Logo usage
- `thadam-logo-dark.svg`: wordmark for dark backgrounds.
- `thadam-logo-light.svg`: wordmark for light backgrounds.
- `thadam-mark.svg`: standalone geometric T mark.
- `thadam-icon.svg`: square app/favicon icon.
- Keep the wordmark and mark proportions intact; do not redraw the T with a different geometry.
- Use the standalone mark for small contexts such as favicons, avatars, and app icons.
- Use signal orange for the mark; use the background-appropriate wordmark colors shown in the source SVGs.
- For monochrome use, preserve the exact T geometry and change only the mark color.

## Voice
- Technical, precise, and calm
- Open-source and engineering-led
- Evidence-driven; avoid unsupported performance claims
- Robotics-aware without suggesting Thadam is a robot operating system

## Naming conventions
Use “Thadam” for the project. Proposed component names such as `thadam-core`, `thadam-cli`, and `thadam-sdk-python` are suggestions only and must be checked against registry availability before publishing.

## Consistency rule
All visual assets must derive from the geometric T shown in `thadam-mark.svg`. If the logo changes later, update this source and regenerate all variants together.
