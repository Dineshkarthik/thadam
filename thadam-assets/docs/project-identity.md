# Thadam Project Identity

- **Name:** Thadam
- **Tagline:** The open data plane for robotics.
- **Descriptor:** Open-source robotics data infrastructure
- **Logo:** The canonical geometric `T` mark in `brand/svg/thadam-mark-light.svg`; use the wordmark variants `brand/svg/thadam-logo-light.svg` and `brand/svg/thadam-logo-dark.svg` for light and dark backgrounds.
- **Product thesis:** Connect robotic and industrial data sources, normalize and process events at the edge, buffer safely through outages, and deliver to the data platform of choice.
- **Implementation direction:** Rust-first, edge-native, open source.
- **Name status:** Accepted (ADR-0016); GitHub, crates.io, and PyPI checked, trademark not searched.
- **Brand consistency:** Use the same geometric mark in every product surface, website, README, docs, CLI, social assets, and future illustrations. Do not use a substitute generic node/diamond mark.

## Suggested repository description
An open-source, Rust-first data plane for robotics and industrial telemetry — connect, normalize, process, buffer, and route data from edge to analytics platforms.

## Suggested short README intro
**Thadam is the open data plane for robotics.** It connects robotic and industrial data sources to modern data platforms with edge-native processing, durable buffering, and flexible sinks.
