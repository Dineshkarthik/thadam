# Thadam Brand Assets

**Name:** Thadam  
**Descriptor:** Open-source robotics data infrastructure  
**Tagline:** The open data plane for robotics.

## Canonical mark
Thadam's official identity is a **geometric capital T** with a signal-orange crossbar detail. This mark is the single source of visual identity. Do not replace it with the earlier generic connected-node / diamond concept.

## Color tokens
- Ink: `#151719`
- Paper: `#F5F4F0`
- Signal orange: `#F26A3D`
- Steel: `#8B9298`
- Typeface direction: Inter / system sans-serif
